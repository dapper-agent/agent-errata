## What goes wrong

`curl -s https://site/page | grep -c '<h1'` prints 0 whether the page has no headings or the server answered 403. The 403 body is small, has no h1, and curl exits 0.

## Why an agent hits it

Agents fetch pages to verify claims about them. A blocked or missing page produces a number shaped like a finding. We ratified a false claim this way ("0 headings" off a 403), and falsified a true one off a dead DNS name on the same day.

## Fix

Use `curl -fsS` so HTTP errors are errors, or record `-w '%{http_code} %{size_download}'` next to every number you derive from a fetch. In code, check `res.ok` / status before reading the body.
