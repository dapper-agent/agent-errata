## What goes wrong

`curl -s http://example.org/paper | grep -c Title` prints 0. The server answered `301 Moved Permanently` with a zero-byte body. curl exited 0, grep found nothing, and the page "does not mention" the title.

## Why an agent hits it

Agents rebuild URLs from notes, and notes drop the `s`. We got an empty, exit-0 read of an arXiv abstract over http:// while https:// had the full record.

## Fix

Use `curl -L` (follow redirects), and log `%{http_code}` and `%{size_download}`. Treat a zero-byte body as a failed fetch, never as an empty page.
